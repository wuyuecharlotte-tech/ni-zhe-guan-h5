## 代码交付

## 交付后确认

实施与验证完成、完整候选可审阅后填写；只审计时注明不适用。用户要求暂不部署时保持未部署，确认代码与同意部署分别记录。

- 供用户审阅的完整代码目录/代码包、候选版本/哈希：
- 本轮主要改动、验证结果、风险/未解决项与回退方式（可引用上文）：
- 拟部署目标环境、函数/服务及范围（不涉及部署时注明）：
- 代码审阅确认：待确认 / 已确认（原话与对应候选）：
- 部署授权：未请求 / 待确认 / 明确同意 / 暂不部署（原话、对应候选与范围）：
- 本轮收尾请求（附上述具体产物后再询问；暂不部署时请用户审阅确认候选，准备部署时再确认具体版本及目标范围）：

已有明确覆盖同一候选及范围的授权直接引用，不重复询问；用户只确认代码不作为部署同意。未获明确同意前，不执行上传发布、服务更新、数据库迁移或流量切换。
