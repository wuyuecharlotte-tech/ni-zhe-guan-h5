# 素材批量下载

从真实素材列表取得 selectionId，调用 Shaper MCP `materials_download({selections:[...]})`。单次最多选择 100 项，文件夹和动画项目自动展开为文件，最多 1000 项。最近删除中的对象需要先恢复。

返回 stage=urls_ready 只代表签名地址已生成。将结果保存到工作目录的 download.json，用 [scripts/download.py](../scripts/download.py) 下载真实字节并生成 ZIP：

先运行 `python3 <技能目录>/scripts/download.py --help` 查看参数，直接执行脚本，无需读取源码。

`python3 <技能目录>/scripts/download.py download.json <本轮新的输出目录>`

若平台以文本提供资源，先将脚本保存到工作目录执行。脚本保留子目录、处理同名文件和路径安全，逐文件核对字节数，失败项不会算成功。地址过期时重新获取地址；不要替换成页面预览缩略图。签名 URL 和包含它的 download.json 不写入应用源码或交付包。

读取脚本输出：仅 downloadedCount 代表成功下载数量；失败项包含签名获取失败和真实下载失败。仅成功下载的文件入包。使用 DeliverArtifacts 交付生成的 ZIP 及脱敏报告，从工具返回的真实结果提供可下载文件。用户仅要求下载时，不修改应用或发布 H5；用户要求在应用中使用素材时，按 [use.md](use.md) 将真实文件接入项目，Spine 需解压后本地引用；平台没有交付工具时如实报告已下载到的路径与无法交付的原因。

最终说明成功和失败数量，列出失败原因；只有交付成功才称“已生成可下载的素材包”。不要称已保存到用户电脑，也不要把尚未访问的临时链接称作下载成功。空文件夹没有可下载文件，明确告知。
