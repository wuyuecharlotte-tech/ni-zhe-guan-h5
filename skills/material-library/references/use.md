# 在应用中使用或替换素材

适用于使用素材、替换图片/图标、设置背景、接入音频/视频/模型及 Spine 动画。用户仅管理素材时不创建页面；要求修改应用时继续完成应用修改，不把“已下载”当作“已接入”。

## 普通素材：原始资源 URL 优先

1. 依据用户选择的真实素材 ID 和名称定位原文件。Agent 素材弹窗提供的清单包含原始 `resourceUrl` 与对应附件名，优先使用该 URL；附件和 UI 预览不改变引用规则。仅有素材名时用 `materials_list` 查询，选择含糊时明确对象。
2. 没有 URL 时，内置 MCP 使用 `materials_download({selections:[真实selectionId],purpose:"use"})` 获取所选文件地址；外部环境按 [external-tools.md](external-tools.md) 使用 `use` 命令。`urls_ready` 仅表示取得地址，尚未下载或接入应用。旧环境不支持 `purpose` 时省略它，仍按本说明判断 URL 用途。
3. 验证原始 URL 可在无需素材库登录态的情况下访问，响应内容对应所选原文件。可复用的 HTTP(S) URL 原样用于 `src`、CSS `url()`、音视频或模型加载器，并按所在语法正确转义；不要下载后转换成 base64/data URI 塞入 HTML、CSS、JS。
4. 带 Expires、Signature、OSSAccessKeyId、X-Amz-*、X-Oss-*、X-Goog-*、token 等鉴权/过期参数的链接属于临时传输地址；素材库 `/api/v1/asset-spaces/.../content` 代理、浏览器 `blob:` URL 也不是部署后的资源地址。不能删除签名参数来猜永久 URL。只有临时地址或 URL 无法访问时，获取真实字节保存为项目静态文件并引用本地路径，说明回退原因；缺少文件时报告阻塞，不编造地址或替代图。

素材库卡片上的文件类型图标、缩略图、poster、截图不代表用户选中的原始素材，即便它们有 URL 或 base64。只有原文件本身就是用户所选的图标时，才将该图标作为应用素材使用。显式要求离线包、内联或其他引用方式时按用户要求执行；默认不内联 base64。

## Spine：下载到项目并本地引用

从用户所选完整动画项目或弹窗 ZIP 附件获取真实文件；需要下载时按 [download.md](download.md) 下载并解压到当前项目静态资源目录。保留 `.json`/`.skel` 骨架、`.atlas` 与 atlas 实际引用的贴图及相对路径，不扁平化、不漏掉多页贴图；运行时通过项目本地路径加载。不能用封面、素材库图标、单张贴图或 base64 代替 Spine 动画，不能把临时下载地址写入加载器。单独选中一个 Spine 成员而缺少依赖时，查询所属完整项目或明确缺失文件。

弹窗提供了完整 ZIP 时可直接解压使用，无需重复下载。未引用封面等附属文件不作为新的独立素材引用，沿用 [upload.md](upload.md) 的 atlas 引用原则。

## 完成核对

核对应用中实际使用的 URL/本地路径与所选原素材一致，Spine 的 atlas 贴图路径能解析，未新增未经用户要求的 base64 内联或 UI 占位图。检查实际加载结果；检查受环境限制时如实说明，不能把取得链接或附件当作接入成功。

“其他”素材保持原始字节，按普通资源规则使用真实 URL 或保存到项目静态目录供对应运行时加载；不作为文稿解析，也不自动解包或转为 base64。代码文件不应上传到“其他”。

字体按普通资源规则引用原始 URL 或项目本地文件，通过 CSS `@font-face` 加载；保持原始字体字节，不按文稿解析。
