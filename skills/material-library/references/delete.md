# 素材批量删除

通过 Shaper MCP 执行；用户身份和权限由会话解析。先从真实素材列表取得 selectionId，不按名称猜测 ID。没有列表时使用 `materials_list` 定位，存在同名项先区分。

1. 调用 `materials_delete_prepare({selections:[...]})`，单次选择最多 100 个入口。服务端展开普通文件夹，清单最多 1000 项；动画按整个项目处理。清单包含子文件，普通文件夹在文件清空后删除。准备步骤不会删除素材。
2. 展示返回的完整 targets（过长时提供清单文件）、总数及 warning：**删除可能影响现有使用这些素材的应用；删除的素材可在 30 天内于素材库“最近删除”恢复。普通文件夹本身不保证可恢复。**不能承诺现有应用不受影响。
3. 将返回的 ask 参数原样交给 `ask_user_question`，暂停并等待用户手动选择“确认删除”。“取消”、自由文本或仅选择文件都不得触发删除。自动模式同样必须走手动确认。工具缺失时停止删除并说明原因，不改用 confirmed=true 或模拟用户回答。
4. 只有收到该计划的肯定回答后，调用 `materials_delete({planId})`。服务端校验同一会话保存的确认问题与实际答案。改动清单或过期需重新准备并确认。
5. 根据 result 的 successCount/failureCount/unknownCount 报告结果，区分文件、文件夹和动画项目；列出失败项与原因。返回 running/unknown 不代表完成。重复读取同一 planId 不会重复删除；未确认结果先刷新列表核对，不能新建计划自动重试。
6. 提醒成功删除的素材可在 **30 天内**通过素材库的**最近删除**恢复，按 expiresAt 判断具体有效期。不要提供永久删除或清空回收站操作。
