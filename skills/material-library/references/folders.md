# 上传前选择并确认文件夹

内置 Shaper MCP 和外部下载包均执行本流程。用户说“上传这些文件”只表示上传意图，不代表已选择文件夹；自动模式也不能跳过人工选择。先完成只读查询、本地文件校验和目标确认，再创建文件夹、领取上传票据或发送文件字节。

## 展示真实已有文件夹

- MCP 调用 `materials_list({category:"all",page:1,pageSize:100})`；外部脚本执行 `list '{"category":"all","page":1,"pageSize":100}'`。从素材库根目录开始；用户要求进入子目录时，用真实返回的普通文件夹 `folderId` 作为 `parentId` 重新查第一页。
- 不沿用素材检索的关键词或分类。当前接口的 `folders` 在第一页完整返回，文件分页不影响这一层文件夹清单；无需为列出文件夹翻完文件页。筛选结果中的 `type:"folder"`，按编号展示名称和所在路径，内部保存对应真实 `folderId`。`type:"project"` 是动画项目，不作为任何上传的目标目录；也不进入项目内部选择上传目标。
- 明确展示范围，例如“素材库根目录已有文件夹：……”。子目录按用户选择逐层展开，不把根目录清单说成整个素材库的所有层级。无普通文件夹时说明“当前目录暂无已有文件夹”，仍提供新建方式；查询失败时说明原因并停止，不能声称没有文件夹。

## 让用户选择上传目标

展示已有文件夹后，一次提供以下选择，并包含本次拟上传的文件名或数量：

1. 使用已有文件夹：选择上方编号或路径，可继续进入子目录。
2. 单独新建文件夹：用户自定义名称；需明确创建位置，默认素材库根目录。
3. 单独新建日期文件夹：按用户时区的当天日期生成 `YYYY-MM-DD`（未提供时区时用 Asia/Shanghai），展示计算出的实际名称和创建位置，等待选择；默认日期只是命名方案，不是自动选中的上传目标。

内置环境优先使用 `ask_user_question`，外部使用工具自身的提问能力或普通对话；必须等待真实用户回答。用户明确选择已有目录，或确认包含实际名称及位置的新目录方案，即构成该目标的确认，无需对同一选择再次追问。仅选择“自定义”但未给出名称、仅回复“上传”或含糊的同名目录不算确认；补齐信息后再执行。用户取消、未回复或无法提问时停止，不能代选、静默上传到根目录或自动创建日期目录。

文件夹名称去除首尾空白后须为 1–255 个字符，不能为 `.`、`..`，不能包含 `/`、`\`、空字符或换行。目标目录存在同名文件夹时，说明冲突，让用户选择复用已有目录或确认其他名称（例如日期加后缀）；不得把“新建”静默改为复用、合并或改名。

## 确认后执行

- 已有目录：普通文件上传传入该目录的真实 `folderId`；`spine` / `spine-zip` 则将同一真实文件夹 ID 作为 `parentId` 传入。
- 新建目录：MCP 调用 `materials_folder_create({name,parentId?})`；外部脚本执行 `folder-create '{"name":"用户确认的实际名称"}'`，子目录可加真实 `parentId`。只使用创建结果返回的 `folderId` 上传，不能将名称当作 ID。
- 创建失败或结果未知：停止上传，先刷新该层目录核对；不自动重复创建，不退回根目录，也不改用其他文件夹。工具未提供创建能力时如实说明，请用户在素材库页面创建后再查询选择，不虚构工具或声称已创建。
- 同一批素材拆分上传时沿用已确认的目标，正常分批无需重复确认。文件清单或目标改变时重新确认；最终结果中说明实际上传目录。

## 动画项目的接口边界

`spine` / `spine-zip` 均支持 `parentId`，在该普通文件夹下新建独立动画项目。已有目录或新建目录均使用查询/创建结果的真实 `folderId` 作为 `parentId`，不能传目录名称或 `selectionId`，也不能误传为普通上传的 `folderId` 字段。省略 `parentId` 表示空间根目录，只有用户明确选择根目录时才省略，不能在目标目录无效或上传失败时自动退回根目录。

上传前说明实际保存位置，例如“活动素材/hero”，并确认父目录和项目名称。目标不能是已有 Spine 项目或其内部目录，不支持向已有项目追加文件。ZIP 可用 `projectName` 指定项目名称；目录项目名称来自文件相对路径的共同首段，保留内部引用，不为了放入文件夹而拆散或擅自改名。项目重名时以接口返回的实际名称为准，并在结果中说明。
